# Email Screenshot Images

This directory contains screenshots of the generated email reports.

## Files

- `email_report_part1.png` - Email header, subject line, and report summary section
- `email_report_part2.png` - Report details including insights, action plan, and sentiment chart

## Adding Screenshots

To add new email screenshots:

1. Save screenshots as PNG files in this directory
2. Update the README.md to reference the new images
3. Use descriptive filenames and maintain consistent naming conventions
